# 喵星人三馆奇遇记：15分钟看猫

欢迎来到这场为十岁小观众准备的小展览。我们一起看三只“猫”：一只古埃及的金属猫、一只青铜猫形棺、还有一只待在画室里的猫。它们来自三家不同的博物馆。请记住：下面关于“古人怎么想”的说法，都是根据作品样貌提出的解释，不是已经证实的结论。看的时候多问自己：我看到了什么？这件作品想让我联想到什么？

路线总时长：15 分钟；开场、观察问题和总结包含在各站时间内。

## Cat — Met（5 分钟）

先看这只古埃及的猫。它由含铜金属制成，年代约在公元前664年到公元前30年之间。请留意它的坐姿：身体挺直，前腿并拢，像在安静地等待。在古埃及，猫常和神灵、家庭生活联系在一起——这是一种常见的解读，但这件小猫具体被谁使用、放在哪里，我们并不能从现有信息里知道。把它想成一件“很久以前的猫的形象”，然后仔细找找它身上的线条和转折。

观察问题：这只猫的耳朵、眼睛和尾巴分别让你想到什么？如果它会动，你觉得它下一秒会做什么？

## Cat Coffin — CMA（5 分钟）

现在看克利夫兰艺术博物馆的猫形青铜棺，年代约在公元前305年到公元前30年。它是空心的，说明里面原本可能放过东西。它的样子像一只端坐的猫，身上有长长的轮廓。有人会把它理解为古埃及人重视猫的证据之一，但这只是解释；我们真正能确定的，是它被做成了猫的样子，而且是中空的。比较一下它和上一只金属猫：一个更像小雕像，一个更像容器。

观察问题：你能找到这只猫棺的“开口”或接缝在哪里吗？如果让你给它设计一个盖子，你会画上什么？

## The Cat in the Studio — SMK（5 分钟）

最后跳到1860年的丹麦：大卫·雅各布森画的《画室里的猫》，油画。画里有一只猫待在画室中——画室是画家工作的地方。请找找猫在画面里的位置：它是在看画、看人，还是只在自己的世界里？我们不知道画家为什么把猫放进来，也许是陪伴，也许是好奇，这些都需要你自己判断。和前两件古埃及作品比，这幅画离我们的时代近得多，猫也更像日常生活中的猫。

观察问题：如果这幅画会发出声音，你觉得猫会发出什么声音？画家把猫放在这个位置，是想让我们先看猫还是先看别的东西？

三件作品、三个地方、三种材料：金属小猫、中空猫棺、油画里的猫。它们都让我们看到人怎样观察猫、想象猫。记住：关于“为什么”的说法都是解释，真正可靠的证据是作品本身的样貌和博物馆提供的信息。下次看到猫的图画或雕塑，试着先说出你看到的三个细节，再猜一个故事。
