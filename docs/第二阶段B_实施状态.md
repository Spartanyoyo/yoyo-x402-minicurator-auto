## 已确认的设计约束

- 网络沿用 Base Sepolia 测试 USDC，禁止主网。阶段 2-A 单资源价格仍为 1000 原子单位。
- 云端使用独立钱包：本地向云端支付任务费，云端再向 2-A 的收费资源支付；不上传现有本地买方私钥。
- 任务与账本存入 Durable Objects，成果和中间 JSON 持久保存；内存只承载有大小上限的临时数据，不依赖本机临时路径。
- 每笔付费操作最多签名、提交一次；中断或响应丢失时只读查账，不自动重新购买。
- 模型只提出白名单工具调用；服务、参数、预算、并行数与停止条件由代码执行。模型不能接触密钥或自由指定网络请求。
- 同一钱包的并行交易需要按区间全部相关转账解释余额变化，不能继续使用 2-A 的“区间仅一笔交易”假设；2-A 的严格默认语义保留。
- 本地取件凭证不放入 URL，不写入公开证据。已付款任务可重复取件，无需再支付。
