# 三只猫：姿态、毛发与画室里的故事

**对象：10 岁左右儿童｜时长：15 分钟｜主题：同一种动物，三种艺术表达**  
**制作日期：2026 年 10 月 25 日｜项目：Cross-Museum MiniCurator**

本展览使用本轮 x402 真实采购并完成付款与交付核验的数据。作品名称、作者、年代、媒介和许可来自博物馆 API；中文标题为辅助译名，讲解、展览顺序和观察问题由 Codex 编写。讲解中的感受与故事猜想用于讨论，不作为作品历史事实。

## 导入：用一个词描述猫（1 分钟）

先想一个词：安静、好奇、柔软、机警，或者你自己的答案。接下来看看，这三位作品中的猫，哪一只最像你刚才想到的样子。

## 第一站：直起身子的猫（4 分钟）

![Met 馆藏 Cat，作品编号 552027，公版图片](https://images.metmuseum.org/CRDImages/eg/web-large/LC-04_2_472_EGDP031195.jpg)

| 作品标签 | 馆藏数据 |
|---|---|
| 原题／辅助译名 | *Cat*／《猫》 |
| 收藏机构 | The Metropolitan Museum of Art（Met，美国大都会艺术博物馆） |
| 作品编号 | 552027 |
| 作者 | API 未提供作者姓名，标为未知 |
| 年代 | 公元前 664—30 年，按馆藏记录保留区间 |
| 媒介 | Cupreous metal，铜质金属 |
| 部门 | Egyptian Art |
| 图片权利 | 公版标记为真，CC0 |

**可以这样讲：**

先不看说明，沿着猫的外轮廓看一圈。它的耳朵竖着，前腿向下伸直，身体稳稳地坐着。作品用有体积的金属形体表现猫；即使没有画出每一根毛，我们也能从耳朵、脸和坐姿认出它。你觉得它是在休息，还是注意到了什么？请指着图上的一个细节说明理由。

**观察问题：**

1. 用手在空中描出它的轮廓，哪些地方接近直线，哪些地方是弧线？
2. 如果把耳朵换成向两边垂下，这只猫给你的感觉会怎样变化？

时间建议：安静看图 1 分钟，读标签与讲解 1 分钟，讨论问题 2 分钟。

来源：[Met 作品页](https://www.metmuseum.org/art/collection/search/552027)；[CC0](https://creativecommons.org/publicdomain/zero/1.0/)；[本轮付费详情与审计](../evidence/phase2a/purchases/met-artwork-1792905093025.json)。

## 第二站：毛发和蝴蝶（4 分钟）

![CMA 馆藏 Cat and Butterfly，作品编号 152829，CC0 图片](https://openaccess-cdn.clevelandart.org/1985.71.5/1985.71.5_web.jpg)

| 作品标签 | 馆藏数据 |
|---|---|
| 原题／辅助译名 | *Cat and Butterfly*／《猫与蝶》 |
| 收藏机构 | The Cleveland Museum of Art（CMA，克利夫兰艺术博物馆） |
| 作品编号 | 152829；馆藏号 1985.71.5 |
| 作者 | Min Zhen，按馆方记录名保留 |
| 年代 | 1788 年 |
| 媒介 | Album leaf, ink on paper；册页，纸本水墨 |
| 文化／部门 | 中国，清代；Chinese Art |
| 图片权利 | CC0 |

**可以这样讲：**

这只猫看起来毛茸茸的。仔细看，它的身体上有很多细细的线，线条随着身体和尾巴的形状转弯。画面没有用浓厚的颜色填满，仍然让我们想到了毛发的触感。再找一找右上方的小蝴蝶：大大的猫和小小的蝴蝶，谁先吸引了你的眼睛？画面中间的空白，也让我们有时间在两者之间来回看。

**观察问题：**

1. 找一处让你觉得“很柔软”的地方，说明是哪些线条产生了这种感觉。
2. 如果蝴蝶被移到猫的脚边，画面的感觉会不会改变？为什么？

时间建议：寻找蝴蝶和线条 1 分钟，读标签与讲解 1 分钟，讨论问题 2 分钟。

来源：[CMA 作品页](https://clevelandart.org/art/1985.71.5)；[CC0](https://creativecommons.org/publicdomain/zero/1.0/)；[本轮付费详情与审计](../evidence/phase2a/purchases/cma-artwork-1792906617520.json)；[艺术家关联核验](../evidence/phase2a/purchases/cma-artist-1792907255236.json)。

数据说明：艺术家接口的文字描述为“1730—1788 年之后”，而 `deathYear` 为“1788”，两者存在冲突；`biography` 为空。本展览不推断确定卒年，也不补写未经来源支持的生平。

## 第三站：画室里的猫（4 分钟）

![SMK 馆藏 The Cat in the Studio，作品编号 KMS3402，公版图片](https://iip-thumb.smk.dk/iiif/jp2/cn69m765x_kms3402-cropped.tif.jp2/full/!1024,/0/default.jpg)

| 作品标签 | 馆藏数据 |
|---|---|
| 原题／辅助译名 | *The Cat in the Studio*／《画室里的猫》 |
| 收藏机构 | Statens Museum for Kunst（SMK，丹麦国家美术馆） |
| 作品编号 | KMS3402 |
| 作者 | David Jacobsen |
| 年代 | 1860 年 |
| 媒介 | Oil on canvas，布面油画 |
| 图片权利 | `public_domain=true`；Public Domain Mark |

**可以这样讲：**

这幅画把猫放进了一个房间。它低着头，面前有一个盘子；后面还能看到画框和打开的箱子。你可以先看猫，再沿着地板、物品和背景慢慢找线索。与前两件相比，我们更容易开始猜一个故事。但要记住：“图上有盘子”是可以指出来的观察，“主人刚刚离开”只是我们提出的一种猜想。

**观察问题：**

1. 找出两件帮助你判断“这里像画室”的物品，并指出它们的位置。
2. 你觉得猫正在做什么？先说一个看得见的细节，再说你的猜想。

时间建议：寻找房间中的物品 1 分钟，读标签与讲解 1 分钟，讨论问题 2 分钟。

来源：[SMK 作品页](https://open.smk.dk/artwork/image/KMS3402)；[Public Domain Mark](https://creativecommons.org/publicdomain/mark/1.0/)；[本轮付费详情与审计](../evidence/phase2a/purchases/smk-artwork-1792908060324.json)。

## 一起看三只猫（2 分钟）

回到最开始想到的那个词，现在把它送给其中一件作品。用“我选择它，因为我看到了……”来回答。

再选一项比较：哪一件最突出姿态，哪一件最让你想到毛发的触感，哪一件给了你最多故事线索？答案可以不同，关键是找到画面依据。

最后想一想：如果你要创作第四只猫，你会选择金属雕塑、水墨还是油画？你想让别人注意到猫的什么特点？
